(i)

∠DEG = ∠CEF (vertically opposite angles); DE = EC (E is the midpoint of DC)1
∴ △GDE ≅ △FCE (angle, angle, side)1
(ii)
From the congruence, GE = EF (corresponding sides)1
In GDCF the diagonals GF and DC bisect each other (GE = EF and DE = EC), so GDCF is a parallelogram1
(iii)
In △HBF and △FCE: ∠HBF = ∠ECF (corresponding angles, HB ∥ EC)1
∠HFB = ∠EFC (common angle); so the third angles are equal and △HBF is equiangular with △FCE1
△FCE ≅ △GDE (part (i)), so △HBF and △GDE are equiangular1
(iv)
△HBF ∼ △ECF: HBEC = BFCF. BF = BC − CF = 23 BC, so BF : CF = 2 : 11
