Introduction

A quadratic equation is an equation of the form ax2 + bx + c = 0 (a ≠ 0).

Steps to solve by factorisation

  1. Write the equation in the form ax2 + bx + c = 0.
  2. Factorise the left-hand side.
  3. Set each factor equal to zero and solve for x.
Example 1

x2 − 5x + 6 = 0

(x − 2)(x − 3) = 0

x = 2 or x = 3

Example 2

2x2 + 7x − 15 = 0 → (2x − 3)(x + 5) = 0 → x = 32 or x = −5
